# Changelog

## 1.1.0

- The image embed now carries the alias `ink` (`![[image.png|ink]]`), so themes and CSS snippets can recolor handwriting on a dark background. The Istari theme does this.
- First public release. Tested on the Supernote Nomad with Chauvet 3.31.45.

## 1.0.0

- Lasso button "Send to Obsidian". Title screen. Saves the lasso PNG and a Markdown note to the inbox folder.
- One setting: the inbox folder.
